# Download and run

The complete English package is `NPUSim_Prof_Live_Demo.tar.gz`.
No update or additional archive is needed.

```bash
sha256sum -c NPUSim_Prof_Live_Demo.tar.gz.sha256
tar -xzf NPUSim_Prof_Live_Demo.tar.gz
cd NPUSim_Prof_Live_Demo
bash start.sh
```

Open `START_HERE.md` for requirements and `RESULTS.html` for saved results.
The extracted package works offline; CANN and host build tools must already be installed.
